# useroutput

A writing standard for every reply a human reads: an answer, a report, a review, a plan, a PR body, a README, a CHANGELOG, or a release note.

Three layers shape the text. Structure decides the shape and the length: a short first sentence with the answer, at most three findings, one fact per bullet, references pushed to a named file instead of inline citations. Language follows ASD-STE100, the controlled English standard: one instruction per sentence, active voice, no jargon padding, no parenthetical asides. Voice strips AI tells: no em dashes, no "delve", no reflexive hedging, no unearned enthusiasm.

The skill never touches reasoning, planning, tool arguments, subagent prompts, or quoted output. It only shapes the final text a person reads.
